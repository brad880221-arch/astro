## 💻 기술 스택 (Tech Stack)

| 구분 | 사용 기술 | 설명 |
| :--- | :--- | :--- |
| **마크업** | HTML5 | 시맨틱 웹 구조, 접근성(ARIA) 및 목차 앵커링 |
| **스타일** | CSS3 (Vanilla) | Slate Navy 다크 테마, 글래스모피즘, 고대비 타이포그래피 |
| **인쇄/출력** | CSS3 `@media print` | A4 규격 출력 최적화, 불필요한 UI 제거 및 여백 조정 |
| **로직** | Vanilla JavaScript (ES6+) | 빌드 프레임워크 없는 순수 자바스크립트 모듈 구조 |
| **데이터 시각화** | HTML5 Canvas 2D | 마우스 호버 툴팁 및 크로스헤어가 내장된 자체 차트 엔진 |
| **스토리지** | Browser LocalStorage | 주간 구독 설정 및 사용자 선호도 영구 보관 |
